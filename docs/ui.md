## 디자인: 다크 + 리퀴드 글래스
- 색은 `theme/app_theme.dart` 의 토큰(`Sb.*`)으로만 쓴다. 포인트 색 **민트 #93E1B7**, 그 위 글자는 짙은 색 `Sb.onAccent`(밝은 민트 위 흰 글자는 잘 안 읽힘).
- 유리 표면(`widgets/glass.dart`): 뒤를 흐리게(`BackdropFilter` blur 24) + 흰색 18% 채움 + 25% 밝은 테두리 + 위쪽이 살짝 밝은 그라데이션 + 그림자.
- 떠 있는 탭바: 화면 좌우 16dp 안쪽, 높이 64dp, 선택한 칸 뒤로 유리 알약이 0.26초 동안 미끄러진다. `Scaffold.extendBody` 로 목록이 탭바 뒤로 비친다. 목록 끝에는 `Sb.tabBarSpace`(104dp) 여백.

## 안드로이드에 맞춘 크기
| 요소 | 크기 | 이유 |
|---|---|---|
| 탭 한 칸 | 폭 ≥ 69dp(360dp 폰), 높이 64dp | 머티리얼 최소 터치 48dp 이상 |
| 탭 아이콘 / 글자 | 24dp / 11sp | 안드로이드 하단 내비게이션 표준 |
| 목록 사진 | 108dp | 360~412dp 폭에서 제목 2줄 + 가격 + 이유가 들어감 |
| 칩 | 높이 36dp(터치 영역 44dp) | 가로 스크롤 칩 |
| 지도 핀 | 높이 36dp + 꼬리, 주변 6dp 터치 여백 | 손가락으로 누르기 쉽게 |
| 유리 원형 버튼 | 48×48dp | 최소 터치 영역 |

## 키보드 버그 수정 (로그인·회원가입)
- 증상: 입력칸을 누르면 화면이 위아래로 출렁이고 버튼이 키보드에 가려짐.
- 원인: `Scaffold` 가 키보드 높이만큼 화면을 줄이는(resize) 동안 `ListView` 가 입력칸을 보이게 스크롤해, 두 동작이 프레임마다 부딪힘.
- 해결: `resizeToAvoidBottomInset: false` 로 화면 높이를 고정하고, `SingleChildScrollView` 의 아래 여백만 `MediaQuery.viewInsets.bottom` 만큼 늘림. 입력칸의 `scrollPadding` 으로 로그인 버튼까지 한 번에 보이게 함. 빈 곳을 누르거나 끌면 키보드가 닫힘.
