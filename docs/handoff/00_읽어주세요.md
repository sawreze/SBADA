## 사용자에 대해
- 한국어로 대화한다. 수업 과제 · 시연용 앱이다(쓰바다 = 물물교환 앱).
- Windows PC(Flutter + IntelliJ)와 M5 맥북을 오가며 개발한다. 맥 프로젝트 경로 `~/dev/SBADA`, GitHub `sawreze/SBADA`(main).
- 비밀값은 절대 공개 레포에 올리지 않는다(강한 요구).
- 디자인 피드백을 화면 캡처로 자주 준다. 요청은 짧게 오므로 기존 디자인 맥락(화이트 모드 + 리퀴드 글래스)에 맞춰 해석한다.
