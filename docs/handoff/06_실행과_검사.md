# 06. 실행과 검사 (맥)

| 하고 싶은 것 | 방법 |
|---|---|
| 전체 테스트 | `전체검사.command` 더블클릭 → 결과 `logs/full-check.log` |
| 앱만 검사 + 웹 빌드 | `앱검사_웹빌드.command`(=`점검.command`) → `logs/check-web.log` |
| 서버 재시작 + 결제 서비스 + 결제 흐름 호출 + 시뮬레이터 | `1순위_점검.command` → `logs/priority1.log` |
| 서버 + iOS 시뮬레이터 | `스바다_실행.command` |
| 켜져 있는 시뮬레이터에 앱만 설치 | `스바다_지금시뮬레이터_실행.command` |
| 시뮬레이터 정리 후 iPhone Duo 로 실행 | `아이폰_앱_다시실행.command` |
| 실제 아이폰 | `아이폰_실기기_실행.command`(케이블 · 신뢰 · 개발자 모드 · Xcode Team 필요) |
| 폰 사파리로 보기(같은 와이파이) | `폰으로_보기.command` |
| 카카오 키 넣기 | `카카오키_설정.command`(키는 화면에 안 보이고 gitignore 파일에만 저장) |

- `.command` 가 "Permission denied" 면 터미널에서 `chmod +x ~/dev/SBADA/*.command`.
- 데모 계정: `scripts/json/login-minji.json`, `login-junho.json`(시연 데이터, 비밀번호는 파일 참고). 관리자 계정은 V12 마이그레이션 참고.
- 서버 주소: 메인 http://127.0.0.1:8097 , 결제 http://127.0.0.1:8098 . 시뮬레이터는 127.0.0.1, 안드로이드 에뮬레이터는 10.0.2.2.
- Xcode 27 에서는 Simulator.app 대신 DeviceHub.app 이 열린다. 화면에 보이는 시뮬레이터와 flutter 가 설치한 기기가 같은지 확인할 것.
