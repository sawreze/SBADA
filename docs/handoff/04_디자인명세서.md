## 리퀴드 글래스 버튼 규칙
- 주 버튼(결제하기 · 수락 · Google 시작 등) = **민트 유리**:
  `background: linear-gradient(180deg, rgba(178,236,204,.85), rgba(147,225,183,.58) 55%, rgba(147,225,183,.72))`,
  `border: 1px solid rgba(255,255,255,.9)`, `backdrop-filter: blur(20px) saturate(180%)`,
  `box-shadow: inset 0 1.5px 1px #fff(95%), inset 0 -2px 6px rgba(47,138,99,.18), 0 8px 22px rgba(47,138,99,.2), 0 0 0 .5px rgba(47,138,99,.28)`.
- 보조 버튼(거절 · 충전 · 칩 등) = **흰 유리**: 같은 구조, 흰색 82% → 48% → 62% 그라데이션, 그림자 #111215 8%.
- 하단 탭바 · 알림창 · 채팅 결제 카드도 흰 유리. 아이콘만 있는 버튼(뒤로 · 삭제)은 배경 없음. 선택된 칩은 검정(#111215) 채움.
- 높이: 큰 버튼 54~56px(둥근 알약), 보조 48px, 칩 32px. 터치 영역 44px 이상.
- Flutter 구현 참고: `widgets/glass.dart` 의 `Glass._liquid()`, `_ClearGlassBar`, `_RimPainter`, `GlassFab`. 라이트 모드 버튼에도 같은 방식 적용 필요(⬜).
