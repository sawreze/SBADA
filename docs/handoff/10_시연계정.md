# 10. 시연용 계정 — 만든 기능을 모든 경우까지 한 계정에서 (2026-11-25)

## 만들기
1. `스바다_실행.command` (서버 · 앱). Kafka(허브)가 켜져 있어야 결제 관련 경우가 만들어진다.
2. **`시연계정_만들기.command`** — 물건 49개(진짜 사진 + AI 가격 분석) + 교환 20건. 몇 분 걸린다.
   - 끝에 `교환 20/20건` · `받은 후기 3개 · 평균 ★4.7` 이 나오면 성공. 기록: `logs/demo-account.log`
   - 경우마다 **내 물건 ↔ 상대 물건 이름**이 기록에 찍힌다 → 채팅 탭에서 그 이름으로 찾으면 된다.
3. 다시 실행하면 예전 시연 계정은 '지난 시연' 으로 정리되고 같은 이메일로 깨끗하게 새로 만들어진다(발표 직전에 한 번 더 실행 추천).

| 계정 | 비밀번호 | 역할 |
|---|---|---|
| **demo@sbada.test** (쓰바다 시연) | sbada1234 | 시연하는 계정 |
| neighbor1@sbada.test (이웃 하늘) · neighbor2 (이웃 바다) · neighbor3 (이웃 숲) | sbada1234 | 상대 화면 보여 줄 때 |

로컬 시연 전용 공개 비밀번호다(실제 서비스 비밀번호 아님). 모두 서울 강남구 역삼동.

## 들어 있는 경우 (demo 기준)
| 코드 | 상태 | 채팅 카드에서 보이는 것 · 눌러 볼 것 |
|---|---|---|
| A1 | 받은 요청 · 내 물건이 더 쌈 | **수락** → '바로 수락 / 추가요금 요청' 창. 추가요금 요청 → 금액 입력 → 💰 카드 |
| A2 | 받은 요청 · 내 물건이 더 비쌈 | 수락 → '추가요금 요청' 이 흐리고 이유(가격)가 보임 |
| B | 보낸 요청 · 상대 수락 대기 | 요청 취소 |
| C1 | 내가 추가요금 요청 → 상대 답 대기 | '상대의 답을 기다리는 중' |
| C2 | 상대가 추가요금 요청 | **수락하고 결제** → 결제 창(가상계좌 · 결제 → 토스 / 카카오페이 '준비 중') / 거절 |
| C3 | 내 추가요금 요청이 거절됨 | **다시 선택** → 바로 수락 · 다시 요청 / 거절 |
| C4 | 상대 요청을 수락함 · 내가 낼 차례 | **결제하기** → 토스 테스트 결제 또는 가상계좌(키 없으면 시연 결제) → 결제 확인되면 자동 성사 |
| C5 | 상대가 수락 · 상대 결제 대기 | '결제가 확인되면 교환이 진행돼요' |
| D1 | 성사 · 운송장 둘 다 없음 | 마감(7일) 표시 · **운송장 번호 입력**(테스트 택배 + 숫자 10~14자리 / 틀리면 '다시 입력') |
| D2 | 내 운송장만 입력 | 상대 칸 비어 있음 · 배송 현황 새로고침 |
| D3 | 상대 운송장만 입력 | 내가 입력하면 둘 다 → 1분마다 단계 막대가 오르고 채팅 · 알림 → 약 4분 뒤 거래 완료 |
| D5 | 추가요금 결제 확인 · 보관 중 + 배송 시작 | 💳 결제 확인 안내 · 운송장 입력 |
| E1 | 거래 완료 · 상대만 후기 | **후기 쓰기**(별 + 글) |
| E2 | 거래 완료 · 서로 후기 | '후기를 남겼어요. 상대도 후기를 남겼어요.' |
| E3 | 추가요금 정산 · 거래 완료 | 보관 돈이 내 지갑으로(계정정보 → 지갑 내역) |
| F1 | 기간 만료 | '기간이 만료되었습니다' · 거래 취소 · 물건이 다시 교환 가능 |
| F2 | 추가요금 결제 후 기간 만료 | 전액 환불(지갑 내역에 환불) |
| G1 · G2 · G3 | 내가 거절 · 상대가 취소 · 상대가 거절 | 끝난 교환(교환 내역) |

그 밖에
- **프로필**: 채팅방 위 상대 이름 또는 물건 상세의 올린 사람 → 물건 목록 + 그 아래 거래 후기. demo 는 후기 3개 · ★4.7
- **찜**: 이웃 둘이 내 물건을 찜(🔔 알림) · 내가 이웃 물건 2개를 찜(계정정보 → 관심목록)
- **지갑**: 10만 원(가상)에서 시작 → F2 결제 · 환불, E3 정산이 내역에 남는다
- **교환 가능한 내 물건 2개**: 다른 계정(tester1 등)으로 새 요청을 보내 처음부터 시연할 수 있다
- 홈 · 검색 · 동네지도(역삼동) · AI 가격 근거는 올린 물건 49개로 확인

## 시연 도구 (dev 프로필에서만 켜짐)
발표 때 기다리지 않으려고 만든 주소(시연계정_만들기 가 쓴다). 운영 설정에는 없다(404).
- `POST /api/demo/exchanges/{id}/deliver-now` — 테스트 택배 두 운송장을 지금 배송 완료로(거래 완료 · 정산까지)
- `POST /api/demo/exchanges/{id}/expire-now` — 운송장 입력 7일이 지난 것으로(만료 · 취소 · 환불)
- `POST /api/demo/retire-me` — demo · neighbor1~3 계정만, 이메일을 비워 다시 만들 수 있게
