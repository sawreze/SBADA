# 09. 직접 손으로 확인하기 — 테스트 계정 체크리스트 (2026-11-25)

## 준비
1. `스바다_실행.command` → 허브(Kafka) + 메인 · 물품 · 결제 서버 + 시뮬레이터 앱
2. `테스트계정_만들기.command` → 아래 계정 3개 + 물건 + 지갑 10만 원(가상)
3. 계정 바꾸기: 앱 **계정정보 → 로그아웃** 후 다른 아이디로 로그인

| 이메일 | 닉네임 | 비밀번호 | 물건 |
|---|---|---|---|
| tester1@sbada.test | 테스트하나 | sbada1234 | [T1] 블루투스 스피커 · 캠핑 의자 · 소설책 세트 |
| tester2@sbada.test | 테스트둘 | sbada1234 | [T2] 무선 이어폰 · 보드게임 · 요가 매트 |
| tester3@sbada.test | 테스트셋 | sbada1234 | [T3] 전기 포트 · 스탠드 조명 |

- 시연 계정도 이메일로 로그인: `admin@sbada.test`, `minji@sbada.test` … (예전 아이디만 쳐도 된다)
- 셋 다 **서울 강남구 역삼동**. admin 과 달리 교환이 '바로 성사' 되지 않는다(상대가 수락해야 함).
- 로컬 시연 전용 비밀번호(다른 시연 계정과 같음). 실제 서비스 비밀번호가 아니다.
- 거래 완료로 물건이 다 떨어지면: 터미널에서 `./테스트계정_만들기.command --새로` (물건 · 지갑을 처음 상태로)

## 체크리스트 (✔ 표시하며 진행)

### A. 로그인 · 홈 (메인 서버 + 물품 서버 GraphQL)
- [ ] 시작 화면 '이메일로 로그인' → 이메일 로그인 화면(카카오 버튼 없음)
- [ ] 한글 입력 상태로 이메일 칸에 `tester1@sbada.test` 를 쳐도 영문으로 들어간다
- [ ] 로그인 화면 맨 아래에 노란 · 검정 줄무늬가 안 뜬다
- [ ] 회원가입: 이메일 · 비밀번호 · 닉네임으로 가입된다(같은 이메일로 또 가입하면 '이미 가입된 이메일')
- [ ] 홈 'AI 추천' 이 뜨고, '최신' · 카테고리 칩 · 위쪽 '상품 N개' 가 보인다
- [ ] 검색: `ㅂㄹㅌㅅ` (초성) → [T1] 블루투스 스피커가 나온다

### B. 물건 올리기 (물품 서버: 사진 · AI 가격)
- [ ] tester1: + 물건 올리기 → 사진 → AI 가격이 나오고 등록된다
- [ ] 등록한 물건이 홈 '최신' 과 계정정보 '내 물건' 에 보인다

### C. 찜 → 알림 (물품 서버 → Kafka → 메인 서버 알림)
- [ ] tester1 로 [T2] 무선 이어폰 ♡ 찜
- [ ] tester2 로 로그인 → 🔔 알림에 '찜' 알림이 와 있다
- [ ] tester1 계정정보 → 관심목록에 이어폰이 있다

### D. 교환 요청 → 수락 (메인 ↔ 물품 gRPC, Kafka)
- [ ] tester1: [T2] 보드게임 상세 → 바로 바꾸기 → 내 [T1] 소설책 세트로 요청
- [ ] tester3: 같은 [T2] 보드게임에 [T3] 전기 포트로 요청(경쟁 요청)
- [ ] tester2: 알림 → 제안 카드 → tester1 요청 **수락**
- [ ] 보드게임 · 소설책 세트가 '거래 완료' 로 바뀐다
- [ ] tester3 로 로그인 → 🔔 '교환 요청이 취소되었어요'(물건이 다른 교환으로 거래 완료)
- [ ] (허브 확인) tester1: [T3] 스탠드 조명에 교환 요청 → tester3: 스탠드 조명 **내리기**(삭제)
      → tester1 에게 '교환 요청이 취소되었어요' 알림(물품 서버 → Kafka → 메인 서버)

### E. 추가 금액 + 안전결제 (결제 서버, 가상 돈)
- [ ] tester1: [T2] 요가 매트에 [T1] 캠핑 의자 + '내가 10,000원 더 낼게요' 로 요청
- [ ] 채팅방 💳 → 수수료 5% 포함 10,500원 결제 → '보관 중'
- [ ] tester2: 수락 → 채팅방에 '시연 모드 · 가상 거래' 표시
- [ ] 두 사람 모두 '물건 받았어요' → 2/2 가 되면 tester2 지갑 +10,000원
- [ ] tester2: 계정정보 → 지갑 → 1원 계좌 인증(입금자명 숫자 4자리) → 출금 → '출금되었습니다'

### F. 채팅 실시간 (WebSocket)
- [ ] 같은 채팅방에서 메시지를 보내면 상대 화면에 바로 뜬다(시뮬레이터 2대일 때) / 다시 들어가면 보인다(1대일 때)
- [ ] 채팅 탭 오른쪽 위에 '실시간 연결됨' 표시가 없다

### G. 프로필 → 판매자 이름 (메인 → Kafka → 물품 서버)
- [ ] tester3: 계정정보 → 닉네임을 '테스트셋2' 로 바꾸기
- [ ] 다른 계정 홈/검색에서 [T3] 물건의 판매자 이름이 '테스트셋2' 로 보인다(몇 초 안에)

### H. 지도 · 탭바
- [ ] 동네지도: 확대 · 축소 · 끌기가 걸리지 않고, 빈 베이지색 칸이 거의 안 보인다
- [ ] 탭바: 끌면 작은 유리 렌즈, 손을 떼면 바로 그 칸에 붙는다

### I. (선택) 장애 격리
- [ ] 물품 서버만 끄기: 터미널 `kill $(lsof -ti tcp:8099)` → 홈 목록은 '불러오지 못했어요', 채팅은 그대로
- [ ] `스바다_실행.command` 다시 → 물품 서버가 다시 켜지고 목록이 돌아온다

문제가 보이면 화면 캡처 + 몇 번 항목인지 알려 주면 된다. 서버 기록: `logs/server.log` · `logs/item.log` · `logs/payment.log`.
